# Tesseriq Website

Marketing website for [tesseriq.in](https://tesseriq.in) — a logistics coordination platform for Indian trucking middlemen.

## Setup

```bash
npm install
npm run dev    # Watch mode (development)
npm run build  # Production build (minified CSS)
```

## Development

Open `index.html` in your browser. The Tailwind CLI watches for changes and rebuilds CSS automatically.

## Deployment

Run `npm run build` then deploy all files (excluding `node_modules/`) to any static hosting provider (Vercel, Netlify, Azure Static Web Apps).

## Pages

- `index.html` — Home (landing page)
- `about.html` — About Tesseriq
- `features.html` — Feature details
- `how-it-works.html` — Step-by-step guide
- `contact.html` — Contact form & info
